Calcul intégral

Un thème de l'épreuve de mathématiques (U41, coefficient 2) du BTS Opticien-Lunetier. Sur cette page : 3 définitions à savoir et 3 questions corrigées.

Les définitions à savoir

  • Primitive

    Probable
    Utilisée dans le sujet 2018

    Une primitive de f sur un intervalle est une fonction F dont la dérivée est f : F' = f.

    Pour comprendre : Deux primitives d'une même fonction diffèrent d'une constante.

  • Intégrale

    Probable
    Utilisée dans les sujets 2016, 2018

    L'intégrale de f entre a et b vaut F(b) − F(a), où F est une primitive de f.

    Pour comprendre : Si f est positive, c'est l'aire du domaine compris entre la courbe, l'axe des abscisses et les droites x = a et x = b.

  • Valeur moyenne d'une fonction

    Probable
    Utilisée dans les sujets 2016, 2018

    La valeur moyenne de f sur [a ; b] est l'intégrale de f entre a et b divisée par (b − a).

    Pour comprendre : C'est la hauteur du rectangle de base [a ; b] qui a la même aire que le domaine sous la courbe.

Type BTS 2018 · Niveau facile

Quelle est une primitive de g(x) = e^(−0,5x) ?

  1. −0,5 e^(−0,5x)
  2. −2 e^(−0,5x)
  3. 2 e^(−0,5x)
  4. e^(−0,5x)
Voir la correction de la question 1

Réponse B. −2 e^(−0,5x)

Une primitive de e^(kx) est (1/k) e^(kx). Avec k = −0,5 : 1/k = −2, donc G(x) = −2 e^(−0,5x). Vérification : G'(x) = −2 × (−0,5) e^(−0,5x) = e^(−0,5x) ✓.

Type BTS 2018 · Niveau moyen

Les ventes mensuelles d'un modèle de monture sont modélisées par f(x) = 6x + 20 sur [0 ; 10]. Quelle est la valeur moyenne de f sur cet intervalle ?

  1. 50
  2. 500
  3. 80
  4. 26
Voir la correction de la question 2

Réponse A. 50

Valeur moyenne = (1 / (10 − 0)) × ∫₀¹⁰ (6x + 20) dx. Une primitive est 3x² + 20x. ∫ = (3 × 100 + 200) − 0 = 500. Moyenne = 500 / 10 = 50. Piège : 500 est l'intégrale, il faut encore diviser par la longueur de l'intervalle.
